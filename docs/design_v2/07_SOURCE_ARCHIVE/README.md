# Echoes of the Aether — Trilogy Canon

This folder is the current canon set for the new three-game direction. It collects
story and design decisions confirmed in the conversation and compatible lore from the
project's existing canon files.

The creator has confirmed that the ideas discussed in chat so far are intended for the
games and are canon. Flexible chapter counts, early playtime targets, placeholder names
and design details can still be revised by the creator as development proceeds.

## Reading order

1. [Trilogy Master Canon](00_TRILOGY_MASTER_CANON.md) — authority, titles and overall
   three-game arc.
2. [Characters](01_CHARACTERS.md) — Aster and Orion across the trilogy.
3. [Echo Systems](02_ECHO_SYSTEMS.md) — Echo, Aether, Echo Rewind, Echo Intel, Echo
   Warp and Echo Relay.
4. [Worlds and Story](03_WORLDS_AND_STORY.md) — Eldara, Veraya, Nalora and the story
   connecting the games.
5. [Creatures, Bosses and Gameplay](04_CREATURES_BOSSES_AND_GAMEPLAY.md) — dungeon
   enemies, world-as-puzzle design, puzzle and combat direction.

## Relationship to earlier project documents

The older files under `CANON/`, `docs/GDD/` and `docs/New Docs/` remain preserved
as source references. They contain substantial detail and useful lore, but many were
written for an earlier cooperative game concept. For the new trilogy, this canon set
supersedes conflicting co-op-only story structure, ability timing and chapter
assumptions. Compatible world and system detail remains useful.
