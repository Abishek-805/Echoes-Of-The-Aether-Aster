# Save, checkpoint, death and completion behavior

**Version:** 2.0 | **Date:** 2026-11-27 | **Status:** Approved V2 direction; implementation details are working specifications

Autosave on rest, major milestone, boss defeat, unique acquisition and ending. Manual save/quit at safe locations. Save persistent world changes separately from transient encounter state. Death is noncanonical failure, not resurrection. On death reload latest safe checkpoint spawn, retain durable progress and restore HP, charges, minimum 50 EE. Ordinary encounters reset, boss defeat permanent. No mandatory corpse run, no penalty for puzzle retries. Rest cools weapons, replenishes health/charges/minimum EE; unique rewards do not respawn. Heat and Rewind cooldown cannot be bypassed during active combat by saving; save/quit limited to safe state. Loading clears Rewind history and damage ledger; rest safely clears cooldown only after deliberate rest.

## Save schema (versioned)
```json
{"schema_version":2,"checkpoint":"OUT01","chapter":1,"hp_max":100,"hp":100,"ee_capacity":100,"ee":60,"heal_charges":3,"weapons_owned":["RIF01"],"equipped":"RIF01","weapon_heat":{"RIF01":0},"rewind_cooldown":0,"materials":{"alloy":0,"biological":0,"relic":0},"guild_marks":60,"flags":["BRIEFED","TUTORIAL_DONE"],"unique_collected":[],"released_echo_tokens":[],"maps_seen":["OUT01"],"archive_ids":[],"upgrades":[],"end_complete":false}
```
Example schema, not a literal save file. Runtime currently stores a versioned JSON envelope and validates checkpoint IDs, flags, map/reward maps, equipment ownership, thermal state, resources and numeric bounds before applying any data. It supports migration from the field names and array forms in this V2 example. It checks both primary and backup semantically, so an invalid but parseable primary cannot mask a usable backup; if neither copy can restore, the campaign displays a recovery warning and leaves both files untouched.

The current runtime persists health, heal charges, weapon ownership/equipment/heat, Echo Energy, Rewind cooldown, progression flags, exploration and unique rewards. Rewind position history and damage ledger are transient and cleared on load. Further work remains for multiple save slots, formal schema migration/version rollover, and hands-on interruption/corruption testing. No autosave occurs during Rewind playback. Persistent rewards and boss flags are committed together; checkpoint snapshots preserve current resources and transient pickups cannot duplicate. Ordinary encounters may reset at checkpoints without duplicating durable rewards. Continue preserves the finale's broken gate and completed signal state. No save transfer is required for the sequel; canon outcome is fixed.
