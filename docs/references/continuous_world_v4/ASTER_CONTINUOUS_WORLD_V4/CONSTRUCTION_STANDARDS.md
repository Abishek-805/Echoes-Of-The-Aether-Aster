# Continuous world construction standards

**Authority:** proposed V4 replaces V3 room layouts only. Approved V2 narrative, heat-based weapons, Echo Collector and Echo Energy, one personal Rewind ability, Orion's rescue and trilogy canon remain. The illustrated concept is artistic inspiration, not a geometric source of truth. This blueprint is a first-pass design, not final collision or runtime proof.

## 1. Scale and coordinate system
- Atlas origin upper-left; +x east/right, +y downward. 1 atlas unit = 16 terrain tiles = 256 logical pixels for initial planning. Extent 126 × 149 atlas units (2,016 × 2,384 tiles, 32,256 × 38,144 px). These are **bounding extents**, not filled terrain, nor a claim about actual travel distance. Use sparse tile chunks. Coordinate placement in Veraya is an atlas inset; VER is a separate physical space/domain. Other regions are in Eldara's sanctuary. Map crossings are not junctions without explicit anchor; resolve schematic crossing by shifting terrain or a clearly authored separate passage, never silently connect routes. A fold is a threshold to another local coordinate space, not a walkable line on the atlas.
- 640×360 logical viewport, 16px tile, Aster visual approx 32×48px; collision capsule may be narrower. Run 150 px/s, jump impulse 300 px/s, gravity 900 px/s², coyote 0.10s, input buffer 0.12s (V2 prototype). The ideal jump rises 50 px and crosses 100 px at same elevation. Required steps ≤32px, gaps ≤64px, headroom ≥64px; do not use theoretical maxima. No double jump, air dash, wall jump, swimming or second supernatural power. Use authored climb points and lifts.
- Nominal lengths in routes.csv are macro estimates based on polylines, not final collision distance; fold length intentionally omitted. Do not stretch empty corridors to fit coordinates. Subdivide long decks with meaningful landmarks; compress where playtests show dead walking. Any geometry changes must preserve graph and story order.

## 2. Build terrain continuously
1. Create full-world coordinate reference and region masks; sketch catchment, cliff, tree, aqueduct, archive and reservoir cross-section before gameplay props. Model walkable paths as continuous silhouettes within those masks, not rectangular screens. Region boundary is a palette/landscape transition, never a loading requirement.
2. Create the global collision spine along approved anchor routes. For each route use its profile (walk, terrace, stairs, lift, ladder, viaduct, fold); generate **hand-authored contour** between elevations. Never rasterize atlas diagonal into a giant slope. Shape terrain first, test movement second, then dress art.
3. Terrain tiles: paint solid base/interior, top edge, corners, sides and steep walls; add separately tagged one-way platform tops. Collision is on solid/one-way layers only. Keep collision surfaces readable and consistently aligned to pixels. Use terrain sets with top/side/corner transitions and deterministic 3–5 decorative variants. Avoid auto-tile decoration changing collision.
4. Make paths varied: main travel 12–24 tile segments, two-tier ledges 6–12 tiles wide, side vista or clue every 1–2 screens where meaningful, protected interaction decks 8–16 tiles, 4-tile minimum head clearance. Avoid forced zigzags solely to consume time. Side pockets must provide a visible clue, a reward or a view; not every wall can break. Safe lower recovery deck under tutorial gaps.
5. Connect adjacent biome art over 6–10 tiles (grass→moss→stone; roots→alloy; alloy→steel). Add large silhouettes to identify location. Avoid a constant tile texture; use custom landmark props, silhouette, negative space, small decals and local light.
6. Place encounter actors only after traversal and camera pass. Entry floor flat and safe; enemy wind-up visible before damage. Design safe wait pockets for every trap. Save points have enemy-free approach and floor. A moving platform is an authored Node2D/AnimatableBody2D with explicit collision, not tile swapping during use.
7. Add art, atmosphere and wildlife after mechanics are validated. The user should never feel a chunk boundary. Ordinary travel continuous; only actual folds, cinematic and special passages may transition camera or loading presentation.

## 3. Continuous streaming architecture
- `WorldRoot` manages logical coordinates; `EldaraRoot` and `VerayaRoot` represent separate spatial domains. Technical chunks (suggest 64×64 tiles, tune) are implementation storage units, not game rooms, levels or completion goals. Use TileMapLayer per collision/deco family and independent scenes for persistent interactables. Do not preinstantiate the entire bounding rectangle.
- Load camera-visible chunks and a prefetch ring; retain active Rewind history positions and any authored shutter domain until history expires. Never unload a lift while Aster rides it or unload an active boss. Prefetch before crossing; commit only after resource ready. Keep movement continuous. Clear Rewind history only on true fold/domain transition, death, save reload or hard cinematic; normal streaming chunk boundaries must not clear history.
- Persistent `WorldState` keys: stable landmark ID, path ID, flag, unique collectible ID, Echo release transaction ID, gate state, puzzle phase (only durable completion), checkpoint, region discoveries. State survives unload. Seed visual variation and wildlife from stable ID, no gameplay changes from random seed. On respawn recompute gates from flags before placing player.
- At path crossings, do a dedicated collision connectivity review. A 2D game cannot use the same solid location as two independent routes without authored layering/threshold; detour locally or explicitly separate domains and preserve route endpoints. `world.json` is a topology specification, not a ready-made Godot scene.

## 4. Eleven render groups plus HUD
| Group | Purpose | Parallax / behavior |
|---|---|---|
| L00 | Sky, moons, void | 0–0.05 |
| L01 | Mountains, skyline | 0.12–0.20 |
| L02 | Huge tree, distant sanctuary structures | 0.30–0.40 |
| L03 | Midground waterfall, ruins, tanks | 0.55–0.70 |
| L04 | Background birds, hares, fish, insects | Match habitat 0.55–0.90; no collider |
| L05 | Near wall, pipes, clues, props | 1.0; keep text legible |
| L06 | Collision terrain and one-way platforms | 1.0; crisp high contrast edge |
| L07 | Aster, enemies, interactables | 1.0 |
| L08 | Combat tell, Rewind, release | 1.0; above decorative actors |
| L09 | Foreground roots, pillars, leaves | 1.10–1.20; fade around Aster and tells |
| L10 | Weather, light, mist | Variable; reduced motion option |
| HUD | Health, EE, weapon heat, heals, Rewind after acquisition | CanvasLayer; no ammunition |

Use Parallax2D for scrolling groups, nearest-neighbor sampling and integer scaling where possible. Sealed vaults need no sky or birds. Leave clear visual silhouette around player and attack telegraphs. Ambient audio crossfades between habitats; dialogue and tells remain audible. Large occluders fade near Aster; environmental clues cannot be hidden by a foreground prop. Use shape and sound in addition to color.

## 5. Wildlife, climate and material
- Ordinary ecosystem: seed plants → bristle hares/insects → birds/predators; algae → minnows/glassfin/filter shrimp → eels; dead organic material → fungi, crabs and other decomposers. Echo-dependent enemies store bound Echoes; Voruun destroy them. Ambient wildlife never drops EE, cannot be farmed or harmed. No wildlife in sterile active vaults. Background water is not gameplay swimming.
- Outdoor Copperwings, Bristle Hares, Lantern Moths, Ribbonfish; Rootspan Sluice Swifts, Mossback Grazers, Glassfin Shoals, Ripple Eels, Reed Crabs; archive Vault Geckos and Dust Moths; Veraya Silverkites, Prism Beetles; Reservoir Basin Minnows and Filter Shrimp; warped zones Rift Moths only in stable pockets. Spawn 2–6 outdoor actors per visible screen, 0–2 sealed interiors, ≤4 fish per tank or visible shoal group; use pooling, deterministic spawn and visibility culling. State Idle→Forage/Perch/Swim→Flee→Return after 6–12 seconds of quiet. No abrupt on-screen spawning.
- Water network: ordinary catchment → Sluice → Rootspan channels → basin → lower return drainage. Restored garden is a branch, not mandatory for downstream safe release. Echo conduit network is separate: source/receiver/release path. P01 restores main hydraulic flow; M06 restores garden habitat; P06 stabilizes Echo pressure/release, changes hostile ecology; P11 stabilizes local transit approach only. Nothing here repairs global Warp or final gate.
- Palette: Eldara warm bronze #A77C50, nature #88A47D, Veraya #7695B7, pale Vaelari alloy #D6C3A4, EE #56CDC4, Warp #AA85CA, heat amber #E89650, hazard #D56C6C, deep slate #202B34. Use original or license-verified assets only; retain source and license records. No copied commercial game sprites or map geometry.

## 6. Traps, security, secrets
- Standard hazard prototype: warning 1.0s, active 0.6s, recovery 1.6s, 12 damage, 3-tile active width. Tune in runtime. Safe wait niche ≥6 tiles. Steam hiss/vent stripes; prism beam line; rift diamond; pressure gauge and pulse. Do not use undetectable instant damage, blind leaps or arbitrary fake exits. Keep hazard off protected interactions and spawn, no crushing closing gates. Arena seals reset on death and open on defeat.
- Security escalates maintenance (P01/P03), archive (P04), topology (P05), pressure (P06), paired isolators and verification (P07/P08), containment (P10/P11). Required gates display cause and link to clue journal. Gate conditions on reciprocal route, no backdoor without required flag. Local wrong input resets only local state, not history, items or world.
- Hidden branches are motivated by visible signs: repeating glyph, light leaking through seam, footprints, conduit, lower waterline, wind or missing map edge. Reward every deliberate detour with useful lore, equipment, view, shortcut or upgrade. A secret is not essential to finish main story.

## 7. Save, death, economy and HUD
- 14 permanent rest stations retained, relocated to named landmarks. Rest restores HP/healing charges and EE to at least 50, not lower higher EE. Local Rewind service guarantees ≥25 EE and resets practice cooldown. Blade remains usable at zero EE; no ammunition/reloading; weapons heat independently and cool over time. Echo Collector briefly captures and safely releases Echo, then stores released energy, not souls. No Echo recovery from destroyed Echoes; overflow dissipates. Use V2 transaction rules. Critical static mechanisms use local energy source, not player inventory.
- Save on rest, major flags, unique reward pickup, relic acquisition and ending. Death reloads checkpoint, not canonical resurrection; durable flags/unique rewards survive; reset encounter state. No corpse recovery. Checkpoint safe bubble, no moving platform as respawn. If boss retry exceeds 45s in testing, use encounter-local retry spawn linked to current rest, not a new permanent save station.
- HUD: HP, EE, heat, heals, contextual prompts, Rewind after acquisition, boss health only during encounter. No ammo/reload UI. Historical/current map after Warp; record discovered terrain silhouette, path gates and fold icons, not every secret. Mark actual location and barrier type, not full solution. Journal auto-records mandatory clues. Post-Warp town remains historical-only. At ending label final gate physical failure; no false secret-escape marker.

## 8. Playtest gate and pacing
- Target first blind main story 8–9h, optional exploration toward 10h; initial allocation Ch1 ~2h45, Ch2 ~2h15, Ch3 ~3h (Rewind near 5h). This is a pacing hypothesis. Time comes from exploration, encounters, meaningful puzzles, curiosity, not empty walking.
- Every route: two-way travel unless explicit closure; no gate bypass by jump/mantle/streaming/Rewind; no one-way softlock; all local switches reachable at zero EE; safe arrival both ends; camera warning before harm. Test with actual controller including low/short jump and movement assist.
- Blind test ask players to sketch three landmarks, discover optional loops and explain the Sluice/Reservoir logic. Record exploration distance, retries, clue usage, rest travel and story comprehension. Iterate if they repeatedly wander with no new clue, or never find useful side paths. Verify all 56 collectible IDs, 12 major/16 minor puzzles, six bosses, 14 rest points. Final runtime completion requires geometry, AI, scripts, art, audio and end-to-end playtest; static flags cannot prove gameplay quality.
