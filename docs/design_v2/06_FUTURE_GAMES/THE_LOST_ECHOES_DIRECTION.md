# Game III — Echoes of the Aether: The Lost Echoes

**Version:** 2.0 | **Date:** 2026-11-27 | **Status:** Approved V2 direction; implementation details are working specifications

Two-player cooperative finale; Aster combat and Rewind, Orion diagnosis/engineering and eventual Relay. Both use stored EE from controlled release; modern efficiency improves after ancient methods learned here. No new special ability for Aster. One canonical ending, optional epilogue differences; central crisis resolved. This is approved narrative framework, not production-ready co-op implementation.

Antagonistic forces: failed Convergence infrastructure, surviving automated preservation directive, Voruun ecosystem dependent on accumulation. No secret mastermind required. Aster protects and uses personal Rewind; Orion performs engineering manually, uses Intel and validated Relay for teamwork. Relay requires safe endpoints/deployed anchors, no free teleport anywhere, no combat escape; return function possible only valid marked positions. Energy cost/efficiency and networking authority to design later; cannot create energy by transferring between players. No ability bypasses mandatory progression. Cooperative systems need reconnect, save authority, join/leave, safe checkpoint and failure recovery before production approval.

Climax: ship could leave using energy diverted from trapped reservoir, but doing so risks disabling release. They choose controlled release and separate power, shut down central intake, protect living, release departed. Destroyed Echoes cannot be recovered; Voruun not exterminated. Surviving animals retreat; future ecology open. Ship leaves beneath ascending lights and combined themes. Aster accepts irreversible loss; Orion accepts technology's ethical limits. Optional records/side stories alter preserved historical archives and epilogue details only, never undo canonical release/escape. Remaining mysteries: Vaelari survivors, Voruun homeworld, Aether consciousness. No sequel cliffhanger for central crisis.
